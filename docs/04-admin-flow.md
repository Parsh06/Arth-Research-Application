# Admin Flow

Admin Login (Superadmin Role verified via DB)
↓
Admin Dashboard (Overview metrics)
↓
Manage Users (View all users, block/unblock, edit roles)
↓
Manage Approvals (Review pending user portfolios, approve/reject)
↓
Manage Subscriptions (CRUD operations for pricing plans)
↓
CMS (Edit Landing page content, e.g., Hero section)
↓
Settings (Global configurations)
