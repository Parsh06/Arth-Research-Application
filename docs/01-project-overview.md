# Arth Research Application - Project Overview

## Project Goal
To create a premium, state-of-the-art wealth management platform that allows users to subscribe to investment plans, submit their current portfolios, and track real-time stock allocations and PnL. The system must include a robust admin panel for managing approvals, users, and subscriptions.

## Company
Arth Jain (Arth Research Application)

## Vision
Empowering serious investors with data-driven portfolio strategies, real-time market tracking, and seamless wealth engine management in a stunning, highly-responsive neo-brutalist interface.

## Tech Stack
*   **Frontend**: React 19, Vite, TypeScript
*   **Styling**: Tailwind CSS v4
*   **State Management**: Zustand
*   **Authentication**: Firebase Auth (Google Sign-In exclusively)
*   **Database**: Firebase Firestore
*   **Icons**: Lucide React
*   **Animations**: Framer Motion
*   **Routing**: React Router DOM

## Theme
Neo-brutalism. High contrast, bold typography, harsh shadows, vibrant accent colors, and visible borders. A design that feels extremely premium, modern, and distinct.
